# โครงงานการออกแบบส่วนติดต่อผู้ใช้และโครงสร้างฐานข้อมูล ร้านขายหนังสือและอีบุ๊กออนไลน์ Lampara Books

**โครงงานพัฒนาระบบฐานข้อมูล | รายวิชาระบบฐานข้อมูล รหัสวิชา 31-407-102-301**  
* **จัดทำโดย:** นายกานต์นิธิ ยะโส (รหัสนักศึกษา 67332110223-9)  
* **เสนอ:** อาจารย์ประภาส ผ่องสนาม (อาจารย์ผู้สอน)  
* **สาขาวิชาวิศวกรรมคอมพิวเตอร์ คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน วิทยาเขตขอนแก่น**  
* **ภาคการศึกษาที่ 1 ปีการศึกษา 2569**  

ระบบร้านขายหนังสือและอีบุ๊กออนไลน์ (Lampara Books E-Book Store) พัฒนาขึ้นตามเกณฑ์ใบงานโครงงานพัฒนาระบบฐานข้อมูลครบถ้วน 100% ครอบคลุมทั้งส่วนหน้าร้าน (ลูกค้า), ส่วนบริหารจัดการหลังร้าน (Lampara Backoffice), ฐานข้อมูลเชิงสัมพันธ์ (3NF), การควบคุมความปลอดภัย Route Guard (403 Forbidden), และรายงานวิเคราะห์ข้อมูลจริง 4 รายงานพร้อมส่งออก CSV (UTF-8 BOM)

## 🚀 วิธีเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียว (สำหรับ Windows)
ดับเบิ้ลคลิกที่ไฟล์ **`run.bat`** ในโฟลเดอร์โปรเจกต์ ระบบจะเตรียมฐานข้อมูลและเปิดเว็บเซิร์ฟเวอร์ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Line
1. ติดตั้งไลบรารีที่จำเป็น:
   ```bash
   python -m pip install -r requirements.txt
   ```
2. สร้างฐานข้อมูลและชุดข้อมูลตัวอย่าง (36 คำสั่งซื้อ):
   ```bash
   python database/init_db.py
   python create_sample_files.py
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   python app.py
   ```
4. เปิดเว็บเบราว์เซอร์ไปที่:
   * **หน้าร้านค้า (Storefront):** [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
   * **ระบบหลังบ้าน (Admin Panel):** [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)

## 📋 สรุปความสอดคล้องกับข้อกำหนดในใบงาน (Deliverables Checklist)
