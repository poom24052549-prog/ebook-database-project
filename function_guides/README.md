# สารบัญคู่มืออธิบายขั้นตอนการทำงานของแต่ละฟังก์ชัน (Function Guides)
**โครงงาน:** Mini Project Database ร้านขาย E-Book ออนไลน์  
**รายวิชา:** Database Mini Project  

โฟลเดอร์นี้จัดทำขึ้นเพื่อรวบรวมเอกสารอธิบายการทำงานในแต่ละฟังก์ชันของระบบอย่างละเอียด ทั้งในมุมมองของ **กระบวนการทำงาน (Flow)**, **หน้าจอที่เกี่ยวข้อง (UI/Routes)**, **ตารางฐานข้อมูลที่เกี่ยวข้อง (Database Tables)**, และ **คำสั่ง SQL เบื้องหลัง** เพื่อใช้สำหรับการเรียนรู้ การทดสอบระบบ และการนำเสนอต่ออาจารย์ผู้สอน

---

### 💡 วัตถุประสงค์ในการใช้งานเอกสาร
1. **สำหรับเตรียมการนำเสนอ:** สมาชิกในกลุ่มสามารถใช้เอกสารแต่ละไฟล์อ่านทบทวนขั้นตอนและคำสั่ง SQL เพื่อตอบคำถามอาจารย์ตามเกณฑ์ข้อ 9 ในใบงาน
2. **สำหรับอ้างอิงตอนตรวจโค้ด:** สามารถตรวจสอบความสอดคล้องระหว่างหน้าเว็บ ฟังก์ชันใน `app.py` และสคริปต์ SQL ในโฟลเดอร์ `database/` ได้อย่างเป็นระบบ
